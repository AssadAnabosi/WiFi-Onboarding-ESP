Networks

About connecting
  • Tap a network to connect, or the connected one to disconnect.
  • If you opened this page through your router rather than the device's own access point, the page can lose the device while it switches networks.
  • If the connection fails, for example because of a wrong password, the device goes back to the network it was on. If it can't, it turns on its own access point so you can still reach it.
  • If something goes wrong, join the device's access point again or check the serial log.
