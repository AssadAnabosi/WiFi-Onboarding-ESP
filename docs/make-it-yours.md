# Make it yours

Checklist for turning a fork into your own project with its own releases and signing key.

> Outline only. This page is filled in before the v0.1.0 release.

## Checklist

Enable Actions; set `OTA_GITHUB_OWNER`, `OTA_GITHUB_REPO`, `PROJECT_SLUG`; generate keys and store `OTA_SIGNING_KEY`; device defaults; reset `VERSION` and `CHANGELOG.md`; branding; confirm board and layout; optional OTA configuration switch; tag `v0.1.0`.
