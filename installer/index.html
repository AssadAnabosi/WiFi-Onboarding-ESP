Choose your board

Not sure? Pick the one marked Recommended.

Install

  1. Click Connect below.
  2. Your browser lists the serial ports it can see. Pick your board and click Connect. Nothing listed? See No port selected.
  3. Click Install and wait until it says the installation is complete (about a minute). Keep the board plugged in.

Installing erases everything on the board, its saved Wi-Fi and settings included. To update a device that already runs this firmware, use Check for updates on its Settings page instead.

This browser can't talk to USB devices: use Chrome or Edge on a computer. The installer only works on a page opened over HTTPS.

Connect it to Wi-Fi

After installing, the installer asks for your Wi-Fi network and sends it to the board over USB. Once the board has joined, click Visit device to open its web page.

Older versions (and other firmware) may not support this; the installer then just finishes.

Prefer to do it later? Skip this step and join the board's own network instead (by default ESP-Access-Point, password 12345678), then open http://config.local or http://192.168.4.1.

No port selected

If you didn't select a port because you didn't see your device listed, try the following steps:

  1. Make sure that the device is connected to this computer (the one that runs the browser that shows this website).
  2. Most devices have a tiny light when it is powered on. If yours has one, make sure it is on.
  3. Make sure that the USB cable you use can be used for data and is not a power-only cable.
  4. Make sure you have the right drivers installed. Below are the drivers for common chips used in ESP devices:
    • CP2102 drivers: Windows & Mac
    • CH342, CH343, CH9102 drivers: Windows, Mac
    • CH340, CH341 drivers: Windows, Mac

    On the WCH pages, download with the blue button with the download icon.
